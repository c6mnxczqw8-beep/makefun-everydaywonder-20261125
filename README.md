# Everyday Wonder — entry

A program/v1 entry for the make.fun "Everyday Wonder"
bounty. `main.py` writes one sentence to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The sentence:

> A stranger held the train door for nobody in particular, just in case someone was running -- and somebody was.

Wonder with a plot: a door held open for a person who did
not exist yet, and then the person arriving, exactly on cue.
The smallest possible evidence that the world is sometimes
arranged kindly on purpose. See `CANDIDATES.md` for the full
draft list this winner was picked from.
